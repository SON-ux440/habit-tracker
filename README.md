# Habit Tracker

![Python](https://img.shields.io/badge/Python-3.x-blue)
![Status](https://img.shields.io/badge/Status-Completed-success)
![License](https://img.shields.io/badge/License-MIT-green)

A simple console application for tracking daily habits written in Python.

## Features

- Add a new habit
- View all habits
- Edit habits
- Delete habits
- Mark habits as completed
- View statistics
- Save data to JSON
- Automatically load data on startup
- Store the creation date for each habit

## Technologies

- Python 3
- JSON

## How to Run

1. Clone the repository

```bash
git clone <repository_link>
```

2. Open the project folder

```bash
cd Habit-Tracker
```

3. Run the program

```bash
python tracer.py
```
